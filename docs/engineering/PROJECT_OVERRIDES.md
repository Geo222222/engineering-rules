# Project Overrides

Use this file only for project-specific rules that are stricter or more precise than the shared engineering baseline.

Examples:

- exact package boundaries that must not be crossed;
- mandatory service/repository abstractions;
- tenant key names and isolation rules;
- required commands before merge;
- prohibited dependencies;
- provider-specific invariants;
- deployment constraints;
- generated-file ownership rules.

Do not duplicate generic engineering guidance from the shared rule files.
