# Project Context Checklist

Before allowing an AI agent to make broad changes, establish these facts from the repository:

- [ ] Repository root and active branch/worktree
- [ ] Application/package entry points
- [ ] Runtime versions and package managers
- [ ] Frontend framework and state/data conventions
- [ ] Backend framework and service boundaries
- [ ] Database and migration system
- [ ] Authentication model
- [ ] Authorization/RBAC model
- [ ] Tenant/organization/location scoping model
- [ ] External provider adapters and webhook/event flows
- [ ] Background jobs/workers/schedulers
- [ ] Environment/configuration system
- [ ] Unit/integration/e2e test commands
- [ ] Lint/format/type-check/build commands
- [ ] CI workflow expectations
- [ ] Deployment topology
- [ ] Known production-critical flows
- [ ] Known incomplete/mock/certification-required surfaces
